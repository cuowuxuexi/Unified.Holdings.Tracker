# 指数分类功能 - 5分钟快速开始

## 🚀 立即开始

### 第一步：查看默认分类

打开应用后，您会看到默认的两个分类：
```
[大盘] [个股] ⚙️
 ----
```
"大盘"分类包含主要市场指数（上证、深证、恒生、道琼斯等）

### 第二步：添加您的第一个自定义分类

1. 点击 **[+ 添加栏目]** 按钮
2. 输入名称，比如 **"我的关注"**
3. 点击"添加"

现在您会看到：
```
[大盘] [个股] [我的关注] [+ 添加栏目] ⚙️
```

### 第三步：添加指数到新分类

1. 点击切换到 **[我的关注]** 分类
2. 点击右上角的 **⚙️** 设置按钮
3. 在"添加指数到当前栏目"输入框中输入指数代码
   - 例如：`hk00700`（腾讯控股）
4. 点击"添加"或按回车

### 第四步：调整显示顺序

**调整分类顺序：**
- 直接拖动顶部的分类标签

**调整指数顺序：**
1. 点击 ⚙️ 设置按钮
2. 在"当前栏目指数列表"中拖动指数标签

### 第五步：管理您的分类

点击 ⚙️ 设置按钮，您可以：
- 📝 编辑分类名称
- 🗑️ 删除不需要的分类
- 👁️ 显示/隐藏指数（点击指数标签）
- ❌ 删除指数（点击指数标签上的 × ）

## 💡 推荐的分类方案

### 方案 1：按市场分类（适合全球市场关注者）
```
[A股大盘] → sh000001, sz399001, sz399006
[港股]    → hkHSI, hkHSCEI
[美股]    → usDJI, usIXIC, usINX
```

### 方案 2：按关注度分类（适合重点关注几个指数）
```
[每日必看] → 最关心的 3-5 个指数
[定期查看] → 一周看几次的指数
[观察列表] → 偶尔关注的指数
```

### 方案 3：按投资策略分类（适合专业投资者）
```
[追踪指数] → 投资组合对标的指数
[行业轮动] → 各行业板块指数
[风险对冲] → 避险相关指数
```

## ⚡ 快捷操作

| 操作 | 方法 |
|------|------|
| 添加分类 | 点击顶部的 [+ 添加栏目] |
| 切换分类 | 点击顶部的分类标签 |
| 添加指数 | ⚙️ → 输入代码 → 添加 |
| 隐藏指数 | ⚙️ → 点击指数标签（变灰色） |
| 删除指数 | ⚙️ → 点击指数标签上的 × |
| 排序分类 | 拖动顶部的分类标签 |
| 排序指数 | ⚙️ → 拖动指数列表中的标签 |
| 编辑分类 | ⚙️ → 栏目管理 → 编辑 |
| 删除分类 | ⚙️ → 栏目管理 → 删除 |

## ❓ 遇到问题？

### 指数代码格式不正确？
确保使用正确的格式：
- A股：`sh` 或 `sz` 开头 + 6位数字
- 港股：`hk` 开头 + 数字或字母
- 美股：`us` 开头 + 字母

### 看不到新添加的指数？
1. 检查指数标签是否为蓝色（灰色表示已隐藏）
2. 点击指数标签切换显示状态

### 想要恢复默认设置？
在设置中删除所有自定义分类，保留"大盘"和"个股"即可。
