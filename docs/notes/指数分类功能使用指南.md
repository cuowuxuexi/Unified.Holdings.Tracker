# 指数分类功能使用指南

## 📖 快速开始

### 什么是指数分类功能？

指数分类功能允许您创建多个自定义的指数栏目，将不同的指数按照您的需求进行分类管理。比如：
- 按市场分类：A股指数、港股指数、美股指数
- 按行业分类：科技股、金融股、能源股
- 按关注度：重点关注、观察列表

## 🎯 主要功能

### 1. 添加新栏目

**操作步骤：**
1. 在指数卡片区域，找到标签栏末尾的 **"添加栏目"** 按钮
2. 点击按钮，弹出输入框
3. 输入栏目名称（如"港股自选"、"美股科技"）
4. 点击"添加"或按回车键

![添加栏目示意图]
```
[大盘] [个股] [+ 添加栏目] ⚙️
                    ↓
      输入栏目名称：[港股自选]
                [取消] [添加]
```

### 2. 切换栏目

**操作步骤：**
- 点击顶部的栏目标签即可切换到对应栏目
- 当前激活的栏目会显示蓝色下划线

```
[大盘] [个股] [港股自选] [美股科技]
 ----                              ← 蓝色下划线表示当前栏目
```

### 3. 编辑栏目名称

**操作步骤：**
1. 点击右上角的 ⚙️ 设置按钮
2. 在"栏目管理"区域找到要编辑的栏目
3. 点击该栏目右侧的"编辑"按钮
4. 修改名称后点击"保存"

### 4. 删除栏目

**操作步骤：**
1. 点击右上角的 ⚙️ 设置按钮
2. 在"栏目管理"区域找到要删除的栏目
3. 点击该栏目右侧的"删除"按钮
4. 确认删除（⚠️ 注意：会同时删除该栏目下的所有指数）

**注意事项：**
- 至少需要保留一个栏目
- 删除栏目时会弹出确认对话框

### 5. 调整栏目顺序

**操作步骤：**
1. 在顶部标签栏，按住鼠标左键拖动栏目标签
2. 拖动到目标位置后松开鼠标
3. 顺序会自动保存

```
拖拽前：[大盘] [个股] [港股] [美股]
         ↓ 拖动
拖拽后：[港股] [大盘] [个股] [美股]
```

### 6. 添加指数到栏目

**操作步骤：**
1. 切换到目标栏目
2. 点击右上角的 ⚙️ 设置按钮
3. 在"添加指数到当前栏目"区域输入指数代码
4. 点击"添加"按钮或按回车键

**支持的指数代码格式：**
- A股：`sh000001`（上证指数）、`sz399001`（深证成指）
- 港股：`hkHSI`（恒生指数）、`hk00700`（腾讯控股）
- 美股：`usDJI`（道琼斯）、`usIXIC`（纳斯达克）、`usINX`（标普500）

### 7. 管理栏目内的指数

**操作步骤：**
1. 切换到目标栏目
2. 点击右上角的 ⚙️ 设置按钮
3. 在"当前栏目指数列表"区域：
   - **删除指数**：点击指数标签上的 × 按钮
   - **隐藏/显示指数**：点击指数标签本身
   - **调整顺序**：拖动指数标签

**指数标签颜色说明：**
- 🔵 蓝色：指数可见（会显示在卡片区）
- ⚪ 灰色：指数已隐藏（不显示在卡片区）

## 💡 使用技巧

### 技巧 1：按市场组织指数
```
[A股大盘] → sh000001, sz399001, sz399006
[港股]    → hkHSI, hkHSCEI, hkHSTECH
[美股]    → usDJI, usIXIC, usINX
```

### 技巧 2：按关注度组织
```
[重点关注] → 您最关心的 3-5 个指数
[次要关注] → 定期查看的指数
[观察列表] → 偶尔关注的指数
```

### 技巧 3：按行业组织
```
[科技板块] → 科创50、纳斯达克、恒生科技
[金融板块] → 金融指数、银行指数
[消费板块] → 消费指数相关
```

### 技巧 4：混合使用
```
[A股指数]   → 各类A股指数
[我的自选]  → 您关注的个股
[全球市场]  → 全球主要市场指数
[行业指数]  → 各行业板块指数
```

## ⚠️ 注意事项

1. **删除栏目**：删除栏目时会同时删除该栏目下的所有指数，请谨慎操作
2. **数据保存**：所有配置自动保存到本地浏览器，不会丢失
3. **指数代码**：请确保输入正确的指数代码格式
4. **最少栏目数**：至少需要保留一个栏目

## 🔄 数据迁移

如果您之前使用的是旧版本的"大盘"和"个股"分类，升级后：
- 旧的"大盘"数据会自动迁移到新的"大盘"栏目
- 旧的"个股"数据会自动迁移到新的"个股"栏目
- 所有数据和配置都会保留

## ❓ 常见问题

### Q1: 如何恢复默认设置？
A: 清除浏览器的 localStorage 数据，或在开发者工具中删除以下键：
- `indexCategoriesV1`
- `marketIndicesOrderV2`

### Q2: 可以创建多少个栏目？
A: 理论上没有限制，但建议不超过 10 个以保持界面简洁。

### Q3: 指数在不同栏目间如何移动？
A: 目前需要：
1. 在原栏目中删除该指数
2. 切换到目标栏目
3. 重新添加该指数代码

### Q4: 可以在多个栏目中添加同一个指数吗？
A: 可以！同一个指数代码可以添加到不同的栏目中。

### Q5: 栏目顺序和指数顺序会保存吗？
A: 是的，所有的排序都会自动保存到本地浏览器。
