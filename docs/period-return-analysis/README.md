## 🚨 高优先级问题

### 问题 #1: 现金流权重计算浮点精度问题

**位置**：`period-stats.ts:493-508`

**现象**：

```typescript
const weight = remainingSeconds / periodDurationSeconds; // 可能产生0.5000000000000001
weightedCashFlows += cf.amount * weight; // 误差累计
```

**影响**：收益率计算可能有0.01%-0.1%的偏差

**解决方案**：

- 使用定点数计算（将金额转换为分）
- 或引入Decimal.js库

**预计修复时间**：2天

---

### 问题 #2: 基准价格回溯机制不足

**位置**：`base-price.ts:22-108`

**现象**：

```typescript
const KLINE_LOOKBACK_DAYS = 15; // 长假期可能覆盖不了
```

**影响**：年度收益率基准价可能错误

**解决方案**：

- 增加回溯天数至120天
- 多数据源策略
- 预加载基准价格

**预计修复时间**：3天

---

### 问题 #3: 实时价格与历史价格不同步

**位置**：`period-stats.ts:368-382`

**现象**：

- 实时行情和K线数据来源不同
- 可能存在短暂不一致

**影响**：周期收益计算准确性

**解决方案**：

- 统一使用K线数据计算收益
- 保留实时数据用于展示

**预计修复时间**：2天

---

### 问题 #4: 摊薄成本为负导致收益率异常

**位置**：`realtime-pnl.ts:48-50`

**现象**：

```typescript
// 卖出收入超过买入成本时，摊薄成本为负
updatedPosition.totalPnl = marketValueCny - (position.totalCost || 0);
```

**影响**：未持仓但显示盈利

**解决方案**：

- 区分已实现和未实现盈亏
- 增加数据验证

**预计修复时间**：2天

---

### 问题 #5: FIFO算法性能问题

**位置**：`realized-pnl.ts:40-102`

**现象**：LotTracker使用数组，O(n²)复杂度

**影响**：大投资组合（>1000笔交易）计算慢

**解决方案**：

- 使用平衡树优化
- 合并相邻批次

**预计修复时间**：3天
