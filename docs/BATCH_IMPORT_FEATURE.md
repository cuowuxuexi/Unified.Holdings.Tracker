# 批量数据导入功能文档

## 功能概述

批量数据导入功能允许用户通过CSV文件一次性导入多条交易记录，大幅提升数据录入效率。

## 功能特点

✅ **支持多种交易类型**
- BUY (买入)
- SELL (卖出)
- DEPOSIT (入金)
- WITHDRAW (出金)
- LEVERAGE_ADD (增加融资额度)
- LEVERAGE_REMOVE (减少融资额度)
- LEVERAGE_COST (融资利息)
- DIVIDEND (股息分红)

✅ **完善的数据验证**
- 日期格式验证
- 交易类型验证
- 必填字段验证
- 资产代码格式验证
- 数值范围验证

✅ **友好的用户体验**
- CSV模板下载
- 导入预览功能
- 详细的错误提示
- 逐行错误定位
- 部分成功导入支持

## 使用流程

### 1. 下载CSV模板

点击"下载CSV模板"按钮，获取标准格式的CSV文件。

### 2. 填写交易数据

使用Excel或其他表格软件打开CSV文件，按照以下格式填写：

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 日期 | 交易日期 | 是 | 2025-01-15 |
| 类型 | 交易类型 | 是 | BUY / SELL / DEPOSIT 等 |
| 资产代码 | 股票代码 | 买卖时必填 | sh600519 / hk00700 / usAAPL |
| 数量 | 股票数量 | 买卖时必填 | 100 |
| 价格 | 股票价格 | 买卖时必填 | 1850.50 |
| 金额 | 交易金额 | 资金操作时必填 | 50000 |
| 手续费 | 交易手续费 | 可选 | 92.50 |
| 融资额度 | 使用的融资额度 | 可选 | 0 |
| 货币 | 货币类型 | 可选 | CNY / USD / HKD |
| 汇率 | 相对CNY的汇率 | 可选 | 1 |
| 备注 | 备注信息 | 可选 | 买入茅台 |

### 3. CSV格式示例

```csv
日期,类型,资产代码,数量,价格,金额,手续费,融资额度,货币,汇率,备注
2025-01-15,BUY,sh600519,100,1850.50,,92.50,0,CNY,1,买入茅台100股
2025-01-16,DEPOSIT,,,,50000,,,,CNY,1,入金5万元
2025-01-17,SELL,sh600519,50,1860.00,,46.50,0,CNY,1,卖出茅台50股
2025-01-18,DIVIDEND,sh600519,,,5000,,,CNY,1,茅台分红
```

### 4. 上传并预览

- 点击"选择CSV文件"上传填写好的文件
- 点击"预览"检查数据是否正确
- 系统会显示：
  - 总行数、有效行数、无效行数
  - 按类型统计的交易数量
  - 详细的验证错误列表（如有）
  - 完整的数据预览表格

### 5. 确认导入

如果预览无误（无效行数为0），点击"确认导入"按钮执行导入。

导入结果会显示：
- 成功导入的记录数
- 失败的记录数
- 详细的错误信息（如有）

## 验证规则

### 通用规则

1. **日期格式**：必须是有效的ISO 8601格式（YYYY-MM-DD 或 YYYY-MM-DD HH:mm:ss）
2. **交易类型**：必须是支持的类型之一
3. **货币类型**：只支持 CNY、USD、HKD

### 买卖交易（BUY/SELL）

必填字段：
- 资产代码（格式：sh/sz开头为A股，hk开头为港股，us开头为美股）
- 数量（必须大于0）
- 价格（必须大于0）

### 资金操作（DEPOSIT/WITHDRAW/LEVERAGE_ADD/LEVERAGE_REMOVE/LEVERAGE_COST/DIVIDEND）

必填字段：
- 金额（必须大于0）

## API 接口

### 1. 下载模板

```
GET /api/batch/template
```

返回标准CSV模板文件。

### 2. 预览导入

```
POST /api/batch/preview
Content-Type: multipart/form-data
```

参数：
- `file`: CSV文件

返回：
```json
{
  "rows": [...],
  "validationErrors": [...],
  "summary": {
    "totalRows": 10,
    "validRows": 9,
    "invalidRows": 1,
    "byType": {
      "BUY": 5,
      "SELL": 3,
      "DEPOSIT": 1
    }
  }
}
```

### 3. 执行导入

```
POST /api/batch/import/:portfolioId
Content-Type: multipart/form-data
```

参数：
- `portfolioId`: 投资组合ID（路径参数）
- `file`: CSV文件

返回：
```json
{
  "message": "成功导入 9 条交易记录",
  "totalRows": 10,
  "successCount": 9,
  "errorCount": 1,
  "errors": [...]
}
```

## 注意事项

1. **文件大小限制**：最大10MB
2. **文件格式**：只支持CSV格式（.csv扩展名）
3. **编码格式**：推荐使用UTF-8编码，支持UTF-8 BOM
4. **Excel兼容性**：保存时选择"CSV UTF-8（逗号分隔）"格式以确保中文正常显示
5. **数据一致性**：导入前建议备份现有数据
6. **资金检查**：系统会检查资金是否足够，卖出是否超过持仓
7. **部分成功**：如果部分记录导入失败，成功的记录已经保存，失败的需要修正后重新导入

## 常见问题

### Q1: Excel打开CSV文件中文乱码怎么办？

**A**: 使用Excel打开时选择"数据" -> "从文本/CSV"，然后选择"65001: Unicode (UTF-8)"编码。

或者在保存CSV时选择"CSV UTF-8（逗号分隔）"格式。

### Q2: 导入时提示"资产代码格式无效"？

**A**: 资产代码必须以市场前缀开头：
- A股：sh（上海）或 sz（深圳），如 sh600519
- 港股：hk，如 hk00700
- 美股：us，如 usAAPL

### Q3: 可以一次导入多个投资组合的数据吗？

**A**: 不可以。每次导入只能针对一个投资组合。如需导入多个组合，请分别上传。

### Q4: 导入失败后数据会回滚吗？

**A**: 不会。每条记录独立处理，成功的记录已经保存，失败的记录不会影响已成功的记录。

### Q5: 如何处理历史数据？

**A**: 建议按时间顺序导入，确保账户现金和持仓计算正确。先导入入金记录，再导入买卖记录。
