# Design Notes - update-home-hero

## Hero 文案与按钮

- **主标题**：统一持仓视图，像 Claude 一样优雅运营
- **副标题**：实时洞察现金、杠杆与收益，把控多账户资产，同时维持 Stage 3 级别的展示体验。
- **价值要点**
  1. 集成实时市值与风险指标
  2. 一键创建并同步多账户
  3. Claude 风格的清爽界面，适合对外演示
- **主按钮**：`立即创建投资组合`
- **辅助按钮**：`打开高级设置`（触发原有 Modal，填写杠杆字段）

## 低保真布局草图（文字描述）

### 桌面（≥1280px）

- Hero 使用左右 46%/54% 栅格；左列自上而下排列标题、副标题、价值要点、HeroCreateCard。
- 右列固定高度 520px 的插画容器，图片保持 24px 圆角与柔和阴影。
- Hero 背景 `#fdf9f3`，外层圆角 28px，Padding 64px，整体宽度与 PortfolioList 匹配。

### 平板（768–1023px）

- Hero 改为纵向堆叠，图片移至文字下方，Padding 收缩至 48px。
- Portfolio 列表维持 2 列（若宽度不足自动降为 1 列），卡片间距 20px。

### 移动（≤640px）

- Hero 内容改为单列居中，标题字号 28px，价值要点改为紧凑列表（可隐藏装饰图标）。
- 表单字段全宽堆叠，按钮高度 ≥48px；Portfolio 列表为单列并取消多余阴影，确保无横向滚动。
