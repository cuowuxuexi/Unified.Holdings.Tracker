# Change: 修复外币交易（卖出、股息）的汇率换算问题

## Why

当前系统在处理港股和美股交易时存在汇率换算不完整的问题：
1. **卖出（SELL）操作**：虽然代码中有汇率计算逻辑，但执行时没有正确应用汇率换算，导致100港元直接显示为100元人民币
2. **股息（DIVIDEND）操作**：虽然已添加汇率换算代码，但实际运行时仍未生效
3. **数据持久化问题**：汇率和币种信息没有正确保存到数据库，导致历史交易无法追溯原始币种

这个问题导致用户的投资组合现金余额计算不准确，影响了整体资产统计和收益分析的准确性。

## What Changes

### 问题诊断
1. **前端传递问题**：前端可能没有传递 `currency` 字段到后端
2. **API推断逻辑问题**：后端的币种自动推断逻辑可能在某些场景下未被触发
3. **编译问题**：TypeScript 源码修改后，编译产物可能未更新或未被正确加载
4. **汇率服务问题**：汇率API调用可能失败或返回错误的汇率值

### 修复措施
1. **存储层修复**（`packages/infra/src/storage/storage.prisma.ts`）：
   - 验证 SELL 分支的汇率换算逻辑是否正确执行
   - 验证 DIVIDEND 分支的汇率换算逻辑是否正确执行
   - 确保 `currency` 和 `exchangeRate` 正确保存到数据库
   - 添加详细的调试日志以追踪汇率换算过程

2. **后端API增强**（`apps/backend/src/routes/portfolio.ts`）：
   - 确保币种自动推断逻辑在所有交易类型中都能正确触发
   - 添加日志记录币种推断结果
   - 验证传递给存储层的数据完整性

3. **前端传递修复**（`frontend/src/`）：
   - 检查交易提交表单是否传递 `currency` 字段
   - 如果前端没有传递，确保后端推断逻辑能正确填充

4. **汇率服务验证**（`packages/infra/src/providers/currency-service.ts`）：
   - 验证汇率获取逻辑是否正常工作
   - 确保对港股/美股资产能正确识别币种
   - 添加错误处理和默认汇率回退机制

5. **编译和部署流程**：
   - 确保 infra 包编译后的代码被正确使用
   - 验证后端服务加载的是最新的编译产物
   - 建立自动化的编译-重启流程

### 技术债务清理
- 统一汇率换算逻辑，减少代码重复
- 改进错误处理和日志记录
- 添加单元测试覆盖汇率换算场景

## Impact

### 影响的能力规范
- `transaction-management`: 交易记录管理和处理

### 影响的代码文件
1. **核心逻辑**：
   - `packages/infra/src/storage/storage.prisma.ts` - 存储层汇率处理
   - `packages/infra/src/providers/currency-service.ts` - 汇率服务
   - `apps/backend/src/routes/portfolio.ts` - API路由层

2. **前端提交**：
   - `frontend/src/features/transaction/` - 交易表单组件
   - `frontend/src/store/` - 状态管理

3. **构建和部署**：
   - `packages/infra/package.json` - 编译脚本
   - 后端启动流程

### 影响的交易类型
- **SELL**：卖出港股/美股
- **DIVIDEND**：港股/美股股息收入

### 数据影响
- 历史交易记录可能需要数据修复（如果已有错误数据）
- 新交易将正确保存 `currency` 和 `exchangeRate` 字段

### 用户体验影响
- ✅ 卖出港股/美股时，现金余额将按正确汇率换算
- ✅ 收到港股/美股股息时，现金余额将按正确汇率换算
- ✅ 交易历史显示正确的原始币种和汇率信息
- ✅ 投资组合总资产计算更加准确

## Risk Assessment

### 低风险
- 代码逻辑已存在，主要是调试和验证问题
- 数据库 schema 已支持所需字段
- 不涉及数据库迁移

### 中风险
- 可能需要手动修复已有的错误交易数据
- 汇率API依赖外部服务，需要处理失败场景

## Validation Plan

1. **单元测试**：
   - 测试 SELL 交易的汇率换算
   - 测试 DIVIDEND 交易的汇率换算
   - 测试币种自动推断逻辑
   - 测试汇率服务的API调用

2. **集成测试**：
   - 创建港股买入交易 → 卖出交易，验证汇率换算
   - 创建美股买入交易 → 股息交易，验证汇率换算
   - 验证数据库中保存的 currency 和 exchangeRate 字段

3. **手动测试**：
   - 在UI中添加港股卖出交易，检查现金余额变化
   - 在UI中添加港股股息交易，检查现金余额变化
   - 查看交易历史，确认币种和汇率显示正确

4. **日志验证**：
   - 检查控制台日志中的汇率换算信息
   - 验证汇率API调用成功
   - 确认币种推断逻辑执行
