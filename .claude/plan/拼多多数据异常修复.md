# 拼多多数据异常修复计划

## 任务背景

**问题描述**：
- 拼多多持仓数据显示异常
- 成本价：744.13
- 市值：55750.54
- 占比%：108.81%（❌ 异常：不应超过100%）
- 总盈亏%：111061.94%（❌ 异常：数值过大）

**根本原因**：
1. **前端百分比显示错误**：后端返回小数形式（0-1范围），前端应乘以100显示，但代码中直接显示
2. **可能的数据异常**：成本价过小或交易记录有误，导致盈亏%计算结果异常

---

## 修复方案：混合方案（方案3）

### 方案概述
1. 修复前端百分比显示逻辑（核心修复）
2. 添加后端数据验证机制
3. 创建数据诊断脚本
4. 生成数据修复报告
5. 根据诊断结果修正异常数据（如需要）

---

## 执行步骤

### 步骤 1：修复前端百分比显示逻辑

**文件**：`frontend/src/components/legacy/PositionsTable.tsx`

**修改位置**：第 15-31 行，`renderPnl` 函数

**原代码**：
```typescript
const formattedValue = isPercent
  ? `${value.toFixed(2)}%`  // ❌ 错误：直接显示小数
  : value.toFixed(2);
```

**修改后**：
```typescript
const formattedValue = isPercent
  ? `${(value * 100).toFixed(2)}%`  // ✅ 正确：乘以100转换为百分比
  : value.toFixed(2);
```

**预期结果**：
- 总盈亏% 从 `111061.94%` 显示为正确的 `1110.62%` 或其他合理值
- 如果后端数据本身有问题，会在后续步骤中发现
