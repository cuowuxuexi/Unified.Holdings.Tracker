# 修复批量导入预览功能执行计划

## 任务描述
修复项目的批量导入交易记录的预览功能无法使用的问题。点击预览按钮没反应，控制台出现错误：
```
TypeError: apiClient.previewBatchImport is not a function
```

## 问题根源
前端 `apiClient` 对象中缺少 `previewBatchImport` 和 `executeBatchImport` 方法定义，但后端API端点已正确实现：
- `POST /api/batch/preview` - 预览导入
- `POST /api/batch/import/:portfolioId` - 执行导入

## 执行步骤

### 步骤1：在api.ts中添加预览和执行导入方法
**文件**：`frontend/src/services/api.ts`

**操作**：
1. 在 `apiClient` 对象末尾添加 `previewBatchImport` 方法
2. 在 `apiClient` 对象末尾添加 `executeBatchImport` 方法
3. 确保使用正确的TypeScript类型

**预期结果**：
- `previewBatchImport` 能正确调用 `/api/batch/preview` 端点
- `executeBatchImport` 能正确调用 `/api/batch/import/:portfolioId` 端点
- 与 `BatchImport.tsx` 中的类型定义保持一致

### 步骤2：测试批量导入预览功能
**文件**：`frontend/src/features/transaction/components/BatchImport.tsx`

**操作**：
1. 上传CSV或XLSX文件
2. 点击"预览"按钮
3. 检查是否能正常显示预览数据

**预期结果**：
- 点击预览按钮无错误
- 能显示数据验证结果和错误信息
- 能显示预览表格

### 步骤3：验证批量导入执行功能
**操作**：
1. 在预览成功后点击"确认导入"按钮
2. 检查导入是否成功完成

**预期结果**：
- 导入操作能成功完成
- 显示导入结果统计

## 技术栈
- 前端：React + TypeScript + Vite + Ant Design
- 后端：Node.js + Express + TypeScript + Prisma
- API通信：Axios

## 变更影响
- **修改**：1个文件 (`frontend/src/services/api.ts`)
- **新增**：2个API方法
- **无删除**：保持向后兼容
